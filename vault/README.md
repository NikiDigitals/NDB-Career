## What This Vault Is

This vault supports the NDB-CAREER Business Analyst career readiness programme. It is entirely separate from the LES Zettelkasten (system design and research focused).

**This vault contains:**
- Role research and job description analysis
- Financial services industry knowledge
- BA practice and methodology notes
- Certification study notes (PSM-I, BCS, PL-300, CDMP)
- Portfolio project working notes
- Application tracking and interview preparation

**This vault does not contain:**
- LES system design or technical architecture
- Formal education notes (ACCA, OU BSc)
- General research (those live in the LES vault)

## Vault Structure

```

├── 02 Industry Knowledge/

│   └── BA Practice/       ← Requirements, stakeholder mgmt, methodologies
├── 03 Certifications/
│   ├── PSM-I/
│   ├── BCS BA Foundation/

├── 05 Application Tracking/← Live applications, contacts, status

```

## Zotero Integration

This vault connects to the `NDB-CAREER` Zotero collection. Sub-collections:

- Data Governance
- Financial Services
- BA Practice
- Certifications
- Industry Reports

All literature enters via Zotero first, then imported as literature notes using the Literature Note template.

## Note Types

| Type | Template | Folder |
|---|---|---|
| Literature Note | `Templates/Literature Note` | Relevant subject folder |
| Role Research | `Templates/Role Research` | 01 Role Research/ |
| Application | `Templates/Application` | 05 Application Tracking/ |
| Interview Prep | `Templates/Interview Story` | 06 Interview Prep/ |
| Project Note | `Templates/Portfolio Project` | 04 Portfolio Projects/ |

---

## Inbox Protocol

All new notes go to `00 Inbox/` first. Process inbox on each working session:
- File to correct folder
- Add tags
- Link to relevant notes
- If literature: ensure Zotero entry exists
